MIDI 声部分离器
上传 MIDI，按旋律与声部关系拆成多个音轨，每条在同一时刻只有一个音符。可以直接试听、逐轨下载，也可以对某一条再继续拆分。
浏览器本地处理 文件不上传 离线可用 保留 BPM / 拍号 / 调号

算法：起始时刻分组 → 单调匹配（voice leading）动态规划 → 单音化校验 → SMF 重写；单轨再分离采用乐句切分 + 音高归并。
试听由 Web Audio 实时合成（钢琴音色为谐波加法合成 + 击槌瞬态 + 轻微房间混响），不加载任何外部音色文件，可完全离线使用。
